# Taski

Персональный канбан-трекер для macOS. Промышленный дизайн, работает полностью офлайн, данные хранятся локально.

![Taski Board](assets/Taski.icns)

---

## Возможности

- **Доски** — несколько досок (Работа, Дом, Учёба, Свой проект), перетаскивание карточек между колонками
- **Сегодня** — просроченные задачи и задачи на сегодня с динамической датой
- **Спринт & Бэклог** — недельный спринт с производственным графиком, перетаскивание из бэклога
- **Архив** — история закрытых карточек с возможностью восстановления
- **Детальная карточка** — редактирование заголовка, заметок, дедлайна, приоритета, чек-листа; удаление
- **Офлайн** — все скрипты и шрифты скачиваются при первом запуске, после не нужен интернет
- **Тёмная/светлая тема**, выбор акцентного цвета, плотность карточек, шрифт — через панель настроек

## Требования

- macOS 12 или новее
- Python 3 (встроен в macOS)
- Google Chrome, Brave или Safari (для открытия приложения)

## Установка

### 1. Клонировать или распаковать проект

Папка проекта должна лежать в домашней директории:

```
~/Taski/
```

### 2. Первый запуск (нужен интернет — один раз)

```bash
cd ~/Taski
python3 server.py
```

При первом запуске сервер автоматически скачает (~4 МБ):
- React, ReactDOM, Babel
- Шрифты: Public Sans, Archivo Narrow, Archivo, Space Grotesk, JetBrains Mono

После этого приложение работает **полностью без интернета**.

### 3. Иконка на рабочем столе

Скопируй `Taski.app` на рабочий стол. Двойной клик — приложение запускается.  
При первом запуске macOS может попросить разрешение — нажать **Разрешить**.

---

## Запуск

**Через .app (рекомендуется)**

Двойной клик по `Taski.app` на рабочем столе.

**Через терминал**

```bash
cd ~/Taski
python3 server.py
```

Приложение откроется по адресу [http://localhost:27852](http://localhost:27852)

|---------|----------|
| `⌘K` | Быстрое добавление карточки / меню-бар |

## Данные

Состояние сохраняется автоматически (600 мс после изменения):

| Хранилище | Путь |
|-----------|------|
| Основное (JSON) | `~/Library/Application Support/Taski/state.json` |
| Резерв | `localStorage` браузера |

**Сброс данных:** Настройки (`⌘,`) → раздел «Данные» → «Очистить все данные» (двойное подтверждение).

## Структура проекта

```
~/Taski/
├── server.py              # HTTP-сервер + сохранение состояния
├── index.html             # Точка входа
├── data.js                # Начальные данные (примеры)
├── prototype/
│   ├── app.jsx            # Корневой компонент, reducer, роутинг
│   ├── atoms.jsx          # Токены, базовые компоненты (Num, Label, Icon…)
│   ├── board.jsx          # Канбан-доска с drag & drop
│   ├── today.jsx          # Экран «Сегодня»
│   ├── sprint.jsx         # Экран «Спринт & Бэклог»
│   ├── archive.jsx        # Экран «Архив»
│   ├── detail.jsx         # Панель карточки
│   ├── menubar.jsx        # Попап быстрого добавления
│   ├── sidebar.jsx        # Навигация
│   ├── state.js           # Инициализация стейта
│   └── tweaks-panel.jsx   # Панель настроек
└── assets/
    ├── react.js           # React (локальная копия)
    ├── react-dom.js       # ReactDOM
    ├── babel.js           # Babel standalone
    ├── fonts.css          # Google Fonts (локальная копия)
    ├── fonts/             # Шрифтовые файлы .woff2
    └── Taski.icns         # Иконка приложения
```

## Стек

| Компонент | Технология |
|-----------|------------|
| UI | React 18, JSX (Babel в браузере) |
| Хранение состояния | `useReducer` + JSON-файл на диске |
| Сервер | Python 3 `http.server` |
| Стиль | Inline styles, токены в `atoms.jsx` |
| Шрифты | Archivo Narrow, Public Sans, JetBrains Mono |
| Упаковка | AppleScript `.app` (macOS) |

---

## Порт

Сервер слушает `127.0.0.1:27852` (только локально, не доступен извне).

Чтобы изменить порт — отредактируй `PORT = 27852` в начале `server.py`.
